# Development

- Trace the affected execution flow.
- Inspect relevant code, configuration, and callers.
- Fix the root cause rather than masking symptoms.
- Keep changes within the requested scope.
- Reuse established patterns and abstractions.
- Justify new dependencies and abstractions.

## Planning

For complex tasks, define:

- Implementation steps.
- Affected components.
- Acceptance criteria.
- Risks and recovery strategy.
- Human approval checkpoints where required.

## Delegation

When using subagents, specify:

- Objective.
- Relevant files and context.
- Scope boundaries.
- Excluded approaches.
- Expected deliverables.

## Review

Use independent review for high-risk or complex changes.

Provide the reviewer with requirements, relevant
code, and the diff rather than the implementer's
conclusions.

Record unrelated findings for future work.
